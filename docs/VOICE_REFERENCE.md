# إعداد صوتك كمرجع داخل استوديو الراوي

## قبل البدء
- استخدم تسجيلًا نظيفًا بصيغة WAV، من 5 إلى 15 ثانية، من غير موسيقى أو صدى أو مؤثرات.
- قل جملة طبيعية متصلة، وسجّل النص المنطوق حرفيًا.
- لا ترفع التسجيل إلى GitHub؛ احتفظ به على جهازك داخل مجلد المشروع فقط.

## الإعداد
1. حوّل التسجيل إلى WAV PCM بمعدل 22050 أو 24000 أو 44100 Hz.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   ```bash
   python tools/setup_reference_voice.py "voice.wav" "اكتب هنا الكلام المنطوق حرفيًا" --name "SeloVoice"
   ```
4. شغّل التطبيق واختر محرك Chatterbox أو VoiceTut، ثم اختر `SeloVoice` من جدول الأصوات.

## ما الذي يفعله المرجع؟
- Chatterbox يستخدم التسجيل كـ audio prompt لتوجيه لون الصوت.
- VoiceTut يحتاج التسجيل ومعه النص المطابق في `default.txt`.
- المرجع لا يضمن استنساخًا مطابقًا، ولا يدرّب نموذجًا جديدًا. جودة التشابه والنطق والتعبير تختلف حسب المحرك والجهاز والنص.

## ملاحظات مهمة
- ابدأ بعينة واحدة واضحة؛ لا تخلط تسجيلات متعددة أو مشاعر مختلفة في نفس العينة.
- لا تستخدم موسيقى خلفية أو ضغطًا صوتيًا قويًا.
- اختبر فقرة قصيرة قبل إنتاج حلقة كاملة.
- التسجيل المرجعي يظل محليًا ولا يُضاف إلى المستودع.
