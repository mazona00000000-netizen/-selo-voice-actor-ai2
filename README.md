# استوديو الراوي 🎙

تطبيق تعليق صوتي بمشاعر لحكايات وبودكاست. بتكتب السكريبت وقبل كل سطر الإحساس بين أقواس، زي `[صوت واطي حزين]`، والتطبيق بيحوّله لأداء صوتي: سرعة، وعلو صوت، ووقفات، وشدة تعبير، ومقاطع مرجعية للإحساس.

التطبيق بتاعك بالكامل، وبيشتغل على جهازك. محركات الصوت قابلة للتبديل:

| المحرك | النوع | المصري | المشاعر |
|---|---|---|---|
| **VoiceTut** (الأساسي) | مفتوح، محلي، مجاني | ✅ متدرّب على المصري | سرعة + وقفات + مقاطع مرجعية |
| **Chatterbox** | مفتوح، محلي، مجاني | عربي عام (وفيه نسخة مصرية اختيارية) | شدة تعبير حقيقية |
| **Darijat** | API مدفوع (تجريبي) | ✅ | أمر أسلوب نصي |
| **تجريبي** | بدون موديل | — | لاختبار الواجهة بس |

## التشغيل

محتاج Python 3.10 أو أحدث.

```bash
git clone https://github.com/mazona00000000-netizen/-selo-voice-actor-ai2
cd -selo-voice-actor-ai2
pip install -r requirements.txt
python -m app.server
```

أو دوس مرتين على `run.bat` (ويندوز) / شغّل `./run.sh` (ماك ولينكس). هيفتح المتصفح على `http://127.0.0.1:8000`.

الواجهة والسيرفر مش محتاجين أي مكتبة إضافية. جرّب الأول بمحرك **تجريبي** عشان تتأكد إن كل حاجة شغالة.

### تركيب محرك VoiceTut (المصري)

1. ثبّت PyTorch المناسب لجهازك من [pytorch.org](https://pytorch.org/get-started/locally/) (كارت NVIDIA يفضّل، والموديل بياخد حوالي 3 جيجا فيديو ميموري).
2. ```bash
   pip install voicetut-tts
   pip install git+https://github.com/k2-fsa/OmniVoice.git
   ```
3. أول تشغيل بينزّل الموديل مرة واحدة، وبعدها بيشتغل أوفلاين.

### محرك Chatterbox

```bash
pip install chatterbox-tts
```

لتفعيل النسخة المصرية (صوت واحد): ضيف `CHATTERBOX_EGYPTIAN=1` في ملف `.env`.

### محرك Darijat (مدفوع)

انسخ `.env.example` لـ `.env` وحط التوكن بتاعك في `DARIJAT_API_TOKEN`. شكل رد الـ API مش موثّق عندهم، فالمحرك ده تجريبي: لو فشل هيعرض لك أول جزء من الرد عشان نظبطه. كل مقطع بيتخصم من رصيدك.

## صيغة السكريبت

```
# سطر بيبدأ بـ # = تعليق، بيتجاهله التطبيق
[هادي] في ليلة من ليالي الشتا، كان الشارع ساكت خالص.

[صوت واطي حزين] قعدت لوحدي أفتكر كل اللي فات.
[وقفة]
[غضب] [صوت عالي] اطلع بره حالًا!
```

- **كل سطر** ممكن يبدأ بإحساس بين أقواس. السطر اللي من غير قوس بيتقرا عادي.
- **أكتر من إحساس** يتجمعوا: `[حزين] [صوت واطي]` أو `[صوت واطي حزين]`.
- **إحساس في نص السطر** بيقسم الجملة: `[حزين] جملة. [فرحان] جملة تانية.`
- **سطر فاضي** = فقرة جديدة. وفي جدول الأصوات بتختار صوت لكل فقرة.
- **`[وقفة]` لوحدها** = صمت.
- **ما تكتبش أسماء المتحدثين** جوه النص، الأصوات بتتحدد من الجدول.

### الأحاسيس المفهومة

حزين، غاضب، فرحان/متحمس، خايف، تشويق/غموض، مفاجأة، هادي، همس، صوت واطي، صوت عالي، بطيء، سريع، وقفة. وبتتفهم بالإنجليزي كمان (`sad`, `angry`, `whisper`, `loud`, `slow`...). أي إحساس مش مفهوم بيتقرا عادي والواجهة بتنبّهك.

عايز تضيف إحساس؟ افتح `app/cues.py` وضيف سطر في قائمة `RULES`.

## مقاطع مرجعية للإحساس (أقوى طريقة)

حط مقطع قصير (5 إلى 15 ثانية) بالإحساس المطلوب في `references/<اسم الصوت>/<الإحساس>.wav`، وجنبه ملف نص بنفس الاسم. شوف `references/README.md`.

## ملاحظات صريحة

- ما اتجرّبش مع الموديلات الحقيقية على جهاز فيه GPU وقت الكتابة، اتجرّب المحلل والتجميع والسيرفر بالمحرك التجريبي. لو ظهر خطأ مع أي محرك، ابعت نص الخطأ.
- VoiceTut بيغلط في بعض الكلمات المصرية (نسبة الخطأ المعلنة 0.40)، فاسمع الناتج وظبط الكلمات الصعبة.
- التطبيق بيشتغل على `127.0.0.1` بس، يعني من جهازك أنت.
